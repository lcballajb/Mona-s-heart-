# Accessibility Plan

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Target WCAG 2.2 AA principles: semantic structure, complete keyboard operation, visible focus, labels and errors, contrast, reflow and zoom, 44px touch targets, reduced motion, accessible dialogs and comboboxes, plain language, and screen-reader announcements. Independent testing is required before claiming conformance.
