# Diagnosis terminology

The provider contract records code, display, system, version, source, retrieval date, user wording, verification, region, language, and active/inactive/retired status. It supports ICD-10-CM in appropriate U.S. workflows, imported FHIR codes, free text, historical versions, and future regional systems. Selection never creates clinical verification and the UI states: “Selecting a condition does not confirm a diagnosis. Mona’s Heart does not diagnose medical conditions.”

SNOMED CT content is **not bundled**. Use requires a verified license, authorized distribution, correct edition/version, jurisdiction assessment, and production access controls. Member-country access does not automatically authorize every deployment or redistribution; legal and terminology licensing review must verify the current rules. Development uses only fictional terms. `SNOMED_PROVIDER_ENABLED` stays false until licensing and regional configuration are approved.
