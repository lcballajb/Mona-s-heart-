# Diagnosis–medication associations

The fixed user-facing title is **“Medications sometimes used for this condition”**. Records require condition code, medication/class, general context, source/date, region, off-label status, authority type, reviewer, review/expiration dates, and workflow status: draft, source verification, clinical review, pharmacist review, approved, published, expired, or withdrawn.

Production displays only unexpired `published` records carrying reviewer, clinical-reviewer, and pharmacist-reviewer evidence. Associations must never derive from popularity, profiles, posts, search frequency, advertising, or model memory alone. Nothing is preselected or added; personal history requires explicit confirmation. Legal, pharmacist, medical, privacy, and source review remain required before publication.
