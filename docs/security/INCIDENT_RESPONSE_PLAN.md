# Incident Response Plan

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Prepare contacts, severity criteria, evidence preservation, containment, credential rotation, vendor coordination, safety/privacy/legal assessment, notification decision process, recovery validation, communications, and lessons learned. Exercise at least annually before production.
