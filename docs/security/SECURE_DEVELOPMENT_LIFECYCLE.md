# Secure Development Lifecycle

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Require reviewed requirements, abuse cases, threat modeling, protected branches, peer review, secret/dependency/static scans, tests, signed artifacts, environment separation, change approval, rollback, and post-release monitoring. Never waive failures without owner, rationale, expiry, and compensating control.
