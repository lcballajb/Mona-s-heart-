# Penetration Test Plan

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Before production, independent testing covers authentication, session/CSRF, object/tenant authorization, roles/admin, APIs, uploads, WebSocket/WebRTC signaling, rate limits, injection/XSS, cloud configuration, mobile/PWA cache, AI boundaries, and privacy leakage. Retest critical findings.
