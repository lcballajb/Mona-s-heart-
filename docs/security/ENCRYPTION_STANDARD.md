# Encryption Standard

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Use current approved TLS in transit and managed encryption at rest with separate key management, least-privileged key access, rotation, backup coverage, and revocation. Do not place secrets in source, browser bundles, logs, URLs, or client storage.
