# Threat Model

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Threats include account takeover, broken object authorization, privilege escalation, cross-tenant access, XSS, CSRF, injection, malicious uploads, prompt injection, secret leakage, unsafe AI output, stalking, harassment, misinformation, supply-chain compromise, denial of service, and audit tampering. Controls must be server-enforced and tested.
