# Access Control Policy

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Deny by default. Server-side authorization validates authenticated subject, tenant, object ownership, role, purpose, consent, block state, and organization relationship for every request. Admin access requires separate strong authentication, least privilege, approval, time limits, and audit.
