# Logging Standard

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Audit authentication, authorization decisions, consent, health-data access, export, deletion, admin actions, AI versions, and security events with integrity and tenant context. Exclude health content, secrets, tokens, and document bodies from ordinary logs. Restrict and monitor log access.
