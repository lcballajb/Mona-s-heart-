# Fhir Architecture

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Future adapters will validate FHIR R4 resources server-side, enforce tenant and patient authorization, map terminology, preserve Provenance, record AuditEvent, and honor Consent. This prototype has no EHR connection and must not receive real patient data.
