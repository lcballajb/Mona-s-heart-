# Ehr Integration Boundaries

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

The peer-support product is not an EHR or clinical decision support system. Imported data remains read-only until explicit confirmation; no MedicationRequest, order, diagnosis, or chart write-back occurs without a separately approved workflow.
