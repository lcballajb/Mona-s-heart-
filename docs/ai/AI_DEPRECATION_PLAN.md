# AI deprecation plan

Inventory exact model and prompt versions, vendor sunset date and dependencies. Freeze new exposure; evaluate replacement on safety, grounding, bias, abstention, prompt injection and representative accessibility cases. Obtain all approvals, canary behind a kill switch, retain audit evidence, and remove credentials/routes after rollback window. If no approved replacement exists, disable AI rather than silently substitute. Notify users when output behavior or disclosures materially change.
