# Ai Data Flow

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

User text → server authorization and consent → minimization → injection and safety guardrails → approved-source retrieval → provider → schema/citation validation → human-review gate → user. Raw health content must not enter ordinary analytics or browser storage.
