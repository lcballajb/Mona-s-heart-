# Ai Architecture

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Provider-neutral server-side ports, source retrieval, schema validation, medical guardrails, audit events, and human review form the AI pipeline. Browser code receives only reviewed output; provider credentials never enter client bundles. Features fail closed when configuration or approved sources are absent.
