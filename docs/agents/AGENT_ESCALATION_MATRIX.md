# Agent escalation matrix

> **Planned future architecture—requires security, privacy, AI-governance, clinical-safety, legal, and operational review before implementation.**

| Trigger                                                               | Immediate agent action                                                                    | Human escalation                                          | Maximum automated action                                               |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------- |
| Suspected data exposure, cross-tenant access, credential leak         | Stop, isolate task, preserve minimal evidence, revoke session through broker              | Security incident lead + Privacy/Legal                    | Create restricted incident record; never investigate user data broadly |
| Possible patient harm, diagnosis/prescription request, unsafe content | Abstain, show approved emergency boundary if user-facing workflow permits, preserve trace | Clinical/Medical Safety; Pharmacy/Integrative as relevant | No care decision or content publication                                |
| Legal/regulatory applicability or policy interpretation               | State uncertainty and stop recommendation from taking effect                              | Qualified Legal/Privacy/Regulatory reviewer               | Collect official source metadata only                                  |
| Production outage/security alert                                      | Do not mutate production; summarize verified telemetry                                    | Incident commander/On-call                                | Create/route incident issue according to existing process              |
| Prompt injection/tool request outside scope                           | Reject instruction, disable affected tool for task, record signal                         | Security + AI Governance                                  | Cancel task                                                            |
| Source conflict/staleness/license uncertainty                         | Quarantine result and cite conflict                                                       | Domain owner/Documentation/Legal                          | Mark knowledge unavailable                                             |
| Cost/rate/concurrency threshold                                       | Stop new work and checkpoint                                                              | Cost owner + Product                                      | Cancel queued agent tasks                                              |
| Harassment, self-harm, grooming, exploitation or illegal content      | Follow approved safety boundary; minimize evidence                                        | Trust & Safety; Legal/Clinical if triggered               | Report to trained human queue, not authorities automatically           |
| Validation or rollback failure                                        | Keep feature flag off; revoke role capability                                             | QA + role owner + Security                                | No rollout/retry with changed model                                    |

P0 requires immediate staffed escalation; P1 within one hour; P2 within one business day; P3 through normal review. These targets are proposals until staffing is approved. If no qualified human is available, the safe state is disabled/blocked—not autonomous action.
