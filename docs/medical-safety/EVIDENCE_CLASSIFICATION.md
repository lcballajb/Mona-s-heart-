# Evidence classification

| Class      | Evidence                                                                        | Allowed language                          | Review                         |
| ---------- | ------------------------------------------------------------------------------- | ----------------------------------------- | ------------------------------ |
| A          | Current regulator/public-health source or high-quality human guideline          | Descriptive within source scope           | Clinical + relevant specialist |
| B          | Peer-reviewed systematic review/meta-analysis with applicable human evidence    | Qualified; include certainty/limits       | Two clinical reviewers         |
| C          | Individual human studies/consensus                                              | Preliminary, never causal beyond evidence | Two reviewers                  |
| D          | Traditional use, patient experience, mechanistic/preclinical evidence           | Clearly labeled; no efficacy claim        | Integrative + Clinical         |
| Prohibited | Fabricated citation, unsupported cure, unsafe instruction, unreviewed AI output | Do not publish                            | Escalate                       |

Source categories include FDA, NIH/NCCIH/ODS, CDC, WHO, MedlinePlus, DailyMed, human-approved guidelines and systematic reviews. Source prestige does not replace applicability and currency review.
