# Rollback checklist

- Declare owner/incident channel and stop rollout; protect users before availability.
- Disable flag/AI/integration without switching to mocks; preserve privacy-safe evidence.
- Confirm schema backward compatibility; restore data only from verified backup with explicit authorization.
- Revert app/config/content/policy as one reviewed unit; rotate compromised credentials.
- Validate health, authorization, audit, queues, notifications, accessibility and key journeys.
- Assess legal/clinical notices and communicate status; monitor recurrence.
- Record timeline, data reconciliation, approvers and follow-up. A destructive migration without tested recovery blocks release.
