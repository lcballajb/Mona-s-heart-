# Disaster recovery

Declare an incident, freeze changes, identify the recovery point, obtain dual approval, restore into isolation, validate integrity/RLS/migrations, rotate possibly exposed credentials, promote only after incident-command approval, monitor, and document. Exercise quarterly and after material architecture changes. Escalate missed RPO/RTO, corrupted backups, key loss, or access anomalies. Legal/privacy/security own notification decisions. Keep a paper-accessible contact tree outside this repository.
