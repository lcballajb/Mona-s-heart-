# Data Classification

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Restricted: health, message, document, credential and precise identity data. Confidential: moderation and internal security material. Internal: plans and reviews. Public: approved site content. Restricted data receives strongest access, logging, encryption, retention, and deletion controls.
