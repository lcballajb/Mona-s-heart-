# Data Flow Map

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Public pages avoid health data. Authenticated health data must move through TLS to authorized server services and encrypted stores. Separate operational metrics from content. AI and EHR flows require explicit consent, minimization, contracts, and audit events.
