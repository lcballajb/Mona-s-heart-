# Privacy Architecture

> Draft—requires review by qualified legal, privacy, security, and healthcare professionals before production use.

Health fields are private by default, purpose-limited, separated from public profile data, and disclosed only after explicit consent and server authorization. Do not sell health data, use it for targeted advertising, add tracking pixels to authenticated health pages, or send health content to ordinary analytics.
